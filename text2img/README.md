# 🏍️ 摩托车头盔商业产品摄影工作流

## 📸 工作流说明

这个工作流用于生成专业级的摩托车头盔商业产品摄影图像。

### 工作流特性

#### 优化的提示词（Positive Prompt）
- 📍 **角度与构图**: 45度角特写、放置在油箱上
- 💎 **细节描述**: 镜片反光、黄金时段、暖色调
- 🎬 **视觉风格**: 商业级、杂志质量、专业工作室灯光
- 📐 **摄影技术**: 浅景深、大光圈虚化、晕影效果
- ✨ **效果**: 8K超高分辨率、电影质感、色彩分级

#### 背景与光线
- 🌄 **背景**: 黄昏盘山公路、蜿蜒山路
- 🌅 **光线**: 晚霞柔光、金色小时、大气雾气
- 💡 **灯光**: 边缘光、轮廓光、专业工作室布光

#### 负面提示词（Negative Prompt）
排除不理想的元素：
- ❌ 模糊、低质量、失真
- ❌ 暗淡的照明、不专业
- ❌ 廉价感、塑料感
- ❌ CGI、过度饱和

### 采样参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **模型** | SDXL Base 1.0 | 高质量基础模型 |
| **分辨率** | 1024×1024 | SDXL最优分辨率 |
| **采样器** | DPMpp 2M Karras | 优化的采样算法 |
| **步数** | 35 | 精细细节 |
| **CFG** | 8.0 | 准确度平衡 |
| **调度器** | Karras | 改进的噪声调度 |
| **上采样** | RealESRGAN x4 | 最终输出8K |

### 使用方法

1. **加载工作流**
   - 在 ComfyUI 中打开 `motorcycle_helmet_commercial.json`
   - 或将文件拖放到工作区

2. **检查模型**
   - 确保有 `sd_xl_base_1.0.safetensors` 模型
   - 可选：配置外部 VAE 改进质量

3. **调整参数**
   - 修改 `Seed` 值获取不同结果
   - 调整 `CFG` 值 (7.0-9.0) 控制准确度
   - 增加 `Steps` (40+) 获得更多细节

4. **生成图像**
   - 执行工作流生成图像
   - 最终输出将是 8K 分辨率
   - 文件保存为 `motorcycle_helmet_commercial_8k_*.png`

### 结果优化建议

#### 如果需要改进
- 🎨 **更多细节**: 增加 Steps 到 40-50
- 📍 **更准确的构图**: 增加 CFG 到 8.5-9.0
- 🌈 **不同风格**: 修改 Seed 重新生成
- 💾 **保存提示词**: 注意生成图像中的嵌入工作流

#### 提示词微调示例
```
"...professional commercial product photography, 8K..."
↓
"...professional commercial product photography, 12K, ultra detailed..."
```

### 常见问题

**Q: 如何获得更好的镜片反光效果？**
A: 在提示词中添加 "specular highlights", "glass reflections", "lens flare"

**Q: 背景太模糊或不够模糊？**
A: 调整 CFG 值，降低会让背景更独立，提高会更紧密跟随提示词

**Q: 生成需要多长时间？**
A: 取决于您的硬件，通常 1-3 分钟。上采样可能需要额外时间。

**Q: 可以生成其他产品吗？**
A: 完全可以！替换提示词中的产品描述即可，工作流结构适用于所有产品摄影。
