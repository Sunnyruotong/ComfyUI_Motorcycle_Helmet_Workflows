# 📋 待办事项应用 (To-Do List Application)

一个功能完整、美观易用的待办事项管理应用，具有本地存储功能，支持离线使用。

## ✨ 主要功能

### 核心功能
- ✅ **添加任务** - 快速输入并添加新的待办事项
- ✅ **完成标记** - 点击复选框标记任务为已完成/未完成
- ✅ **删除任务** - 删除不需要的任务
- ✅ **任务过滤** - 按状态过滤 (全部/进行中/已完成)
- ✅ **统计信息** - 实时显示总数、进行中数量、已完成数量

### 高级功能
- 💾 **本地存储** - 自动保存到浏览器本地存储，刷新页面数据不丢失
- 📥 **数据导入** - 从 JSON 文件导入任务
- 📤 **数据导出** - 导出任务为 JSON 文件备份
- 🗑️ **批量清空** - 一键清空所有已完成的任务
- 📱 **响应式设计** - 完全适配各种设备尺寸
- 🎨 **现代界面** - 渐变背景、流畅动画、优雅过渡效果

## 🚀 快速开始

## 📖 使用说明

### 添加任务
1. 在输入框中输入任务描述
2. 按 `Enter` 键或点击 `➕ 添加` 按钮
3. 新任务将自动保存并显示在列表中

### 管理任务
- **完成任务**: 点击任务左侧的复选框
- **删除任务**: 点击任务右侧的 `删除` 按钮
- **过滤任务**: 使用顶部的过滤按钮切换视图

### 导出数据
1. 点击 `💾 导出` 按钮
2. 系统会下载一个 JSON 文件，文件名为 `todos_YYYY-MM-DD.json`
3. 可用于备份或转移到其他设备

### 导入数据
1. 点击 `📥 导入` 按钮
2. 选择一个有效的 JSON 数据文件
3. 确认导入，现有任务将被替换

### 清空已完成
1. 点击 `🗑️ 清空已完成` 按钮
2. 确认操作后，所有已完成的任务将被删除

## 💾 本地存储说明

### 工作原理
- 应用使用浏览器的 **LocalStorage API** 存储任务数据
- 每次添加、修改或删除任务时，数据会自动保存
- 即使关闭浏览器或刷新页面，数据也不会丢失

### 存储容量
- 浏览器 LocalStorage 通常提供 5-10MB 的存储空间
- 对于大多数用户的任务列表完全足够
- 如果出现存储已满的警告，可以导出数据后清空应用

### 清空存储
- 打开浏览器开发者工具 (F12)
- 进入 `应用` 或 `Application` 选项卡
- 在左侧菜单找到 `本地存储` 或 `Local Storage`
- 选择本应用的域名并清除数据

## 🐛 常见问题

**Q: 数据会永远保存吗？**
A: 数据会一直保存在本地存储中，直到您手动清空浏览器数据或运行清除存储命令。

**Q: 能在多个浏览��间同步数据吗？**
A: 不能。LocalStorage 是本地存储，不会在浏览器间同步。可以通过导出/导入功能手动转移。

**Q: 如果我清空浏览器缓存，任务会丢失吗？**
A: 会丢失。如果您打算清空缓存，请先导出任务数据进行备份。

**Q: 支持离线使用吗？**
A: 完全支持！应用可以离线运行，所有数据都保存在本地。
